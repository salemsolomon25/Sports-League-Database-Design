# Sports-League-Database-Design
SQL database design project featuring an ERD, table creation scripts, sample data inserts, and query examples for a sports league system.


# Project Overview
The database models key sports league entities including seasons, divisions, clubs, teams, players, coaches, and team assignments.

# Features
- Entity Relationship Diagram (ERD)
- Database creation script
- Table creation with primary and foreign keys
- Sample data inserts
- SQL query examples

# Technologies Used
- SQL
- MySQL / MySQL Workbench
- Entity Relationship Modeling

# What I Learned
This project helped me practice relational database design, table relationships, primary keys, foreign keys, data insertion, and querying data from multiple related tables.
